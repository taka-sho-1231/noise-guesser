# README　(EN)
Noise Guesser is a game where you guess the number of steps in the noising process of a diffusion model from a given image.

## How to Play
First, please install the packages listed in `requirements.txt`.
### ipynb
Run
`NoiseGuesser.ipynb`.
### pygame
Run `start_game.py`.
